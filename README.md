# 🏠 HomeBills

HomeBills is a web application for tracking and calculating household utility expenses.
The app allows you to store meter readings, calculate monthly consumption, and clearly see how much you pay for utilities — all in one place.

## 🔑 Core Features

- Utility meters tracking: 💧 Water ⚡ Electricity 🔥 Gas
- Monthly meter readings input
- Automatic consumption calculation
- Cost calculation based on utility tariffs
- History of readings and payments
- Visual analytics and charts
- Local data persistence using localStorage

## 📊 Dashboard Overview

-Monthly utility expenses summary
-Comparison with previous months
-Consumption trends by utility type
-Clear and transparent cost breakdown
